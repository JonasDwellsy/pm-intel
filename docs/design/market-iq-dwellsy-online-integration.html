Guardrails

What the consolidation must not blur

Source honestyTrends, historical export, operator snapshots, and live listings keep separate source dates and claims.
Operator IQ depthMarket IQ provides context and a teaser, never a second implementation of Operator IQ scorecards.
Fail-closed accessEvery premium read requires both product and market entitlement.
No fabricated live feedThe listing ticker remains unavailable until the listing source succeeds and persisted events are verified.
No production-first migrationSchema and UI changes land in a preview deployment before production data is touched.
One delivery systemMarket IQ reuses SendGrid and existing unsubscribe conventions instead of adding Resend.
Recommended first build

A narrow slice that proves the architecture

Market IQ platform seam

The first preview should prove shared identity, entitlement, navigation, design, and data access before porting the full dashboard.

  1. Add product entitlements with an additive Prisma migration and admin grant control.
  2. Add a Dwellsy IQ product switcher that identifies Operator IQ and Market IQ without renaming stable Operator IQ routes.
  3. Add a protected /market-iq route using the current Clerk organization and market grants.
  4. Render the Cleveland MSA overview using source-dated Dwellsy IQ trend and July historical baseline data.
  5. Add source-health and methodology disclosures before any account-owned workflow.
  6. Ship to a Vercel preview deployment with no production database mutation.
